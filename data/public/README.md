# Open dataset

The items and interactions are original fictional educational examples, contributed under the CC0 1.0 public-domain dedication (https://creativecommons.org/publicdomain/zero/1.0/). 12 items, 24 explicit ratings from six artificial users. No actual users, private preferences, or personal data. Intended only for a reproducible model demo; metrics are not evidence of production effectiveness. Extend evaluation to MovieLens, respecting GroupLens download terms and licensing, before real-world claims.
